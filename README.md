# Omkar Ghate — AI Prompt Engineering & Conversational AI

Public portfolio and reusable prompt library for **Omkar Ghate**, an AI builder focused on structured prompt engineering, conversational/voice agents, multilingual interaction design, and workflow automation.

## Areas of focus
- Structured system prompt design and instruction hierarchy
- Conversational AI and voice-agent flows
- Multilingual behavior, interruption handling, clarification, and handoff
- Tool calling, CRM integrations, APIs, and workflow automation
- Prompt QA, edge-case testing, and evaluation

## Repository map
- `index.html` — responsive portfolio landing page
- `prompts/production-voice-agent.md` — voice agent system prompt template
- `prompts/customer-support-agent.md` — support agent prompt template
- `prompts/prompt-qa-checklist.md` — prompt testing checklist
- `case-studies/voice-agent-architecture.md` — reference architecture and evaluation plan
- `.github/workflows/quality-check.yml` — automated basic quality checks

## Use
Templates are starting points. Adapt them to your platform, tools, policy, and actual business process. Test against representative and adversarial cases before production deployment.
